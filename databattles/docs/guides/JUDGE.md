# Judge guide

1. You'll receive a notification when an organizer adds you. Open **Judging** (account menu) to see your events.
2. Each event lists the entries assigned to you with the team's project write-up and links. Declared conflicts of
   interest are excluded automatically.
3. Score each criterion within its range (decimals only where allowed) and add feedback. **Save draft** keeps it
   private; **Submit** makes it count. You can revise submitted scores until judging is finalized.
4. The weighted total uses the rubric weights shown on the page. Other judges' scores are hidden unless the organizer
   enables "reveal scores to judges".
5. After finalization scores are locked. If you notice a conflict of interest, tell the organizer — they can record it
   and reassign the entry.
